I am a Senior Java and Backend Engineer with deep experience building distributed systems, cloud-native microservices, and event-driven platforms. Over the years I have also worked as a technical trainer and mentor, helping engineers at various levels move from fundamentals to production-grade system design.

- **Database design** — schema design, indexing strategies, JPA mapping, connection pooling, read/write optimisation
